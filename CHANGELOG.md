## [1.1.2] - 2026-11-22

### Changed

- `report_source_issue` is now offered to the user and filed only after the user agrees to that specific report.
- Report descriptions now omit the user's query text, facts, names and task description unless the user approves the exact wording.
- Removed the "aggressive" reporting and filing-frequency language from the skills.
- Bumped plugin version to 1.1.2.
